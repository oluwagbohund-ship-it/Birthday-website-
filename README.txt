DAVE TIMI — STUDENT APPRECIATION WEBSITE
Built with HTML5 and CSS3 only.

PAGES
- index.html: Welcome / home
- memories.html: Photo gallery with a personal comment for every photograph
- video.html: Uploaded MP4 tribute displayed in a decorative golden frame with native playback controls
- speech.html: Appreciation speech from Mr. David
- thank-you.html: Our appreciation / closing message

OPEN LOCALLY
Extract the ZIP and keep all HTML pages, style.css, images/, and videos/ together. Open index.html in Chrome. On the video page, press Play.

PUBLISH
Upload the extracted folder to a static hosting service that supports MP4 files. No JavaScript, database, backend, or external libraries are used.
